# Stream Deck Plugins

Six free, open-source (MIT) Elgato Stream Deck plugins by Pavel Kotyza — physical keys for the tools you run all day.

**Live page: https://kotyzap.github.io/Stream-Deck-Plugins/**

## For Axis integrators & operators

- [Deck for AXIS Camera Station Edge](https://github.com/kotyzap/Stream-Deck-ACS-Edge-Plugin) — recording playback, PTZ, view shortcuts
- [Deck for AXIS Camera Station Pro & 5](https://github.com/kotyzap/Stream-Deck-ACS-Pro-Plugin) — playback, cameras, PTZ presets, any hotkey
- [Deck for Genetec Security Desk](https://github.com/kotyzap/Stream-Deck-Genetec-Plugin) — playback, alarms, tiles, PTZ, doors, hot actions
- [Deck for Milestone XProtect](https://github.com/kotyzap/Stream-Deck-Milestone-Plugin) — playback, evidence, PTZ, views, camera by number

## Two more decks

- [Camera Deck for Axis & CamStreamer](https://github.com/kotyzap/Stream-Deck-Axis-Cam-CamStreamer-Plugin) — direct-to-camera PTZ/CamStreamer/CamSwitcher control
- [Deck for Claude](https://github.com/kotyzap/Stream-Deck-Claude-Plugin) — permission prompts, replies, shortcuts and status for the Claude desktop app

All six are free, open source (MIT), and cross-link to each other. This repo just hosts the landing page that ties them together.
