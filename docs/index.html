For Axis integrators & operators

If you run Axis cameras, start here.

Whatever you watch your Axis cameras through, there's a deck for it: AXIS Camera Station Edge, AXIS Camera Station Pro & 5, Genetec Security Desk, and Milestone XProtect Smart Client. Each one wraps that client's own documented keyboard shortcuts — playback, PTZ, alarms, bookmarks, view navigation — plus any camera or view by number, so a stock installation works with no server-side configuration.

Two more decks

The camera itself, and Claude.

Round out the family: one deck talks straight to the camera over VAPIX/CamStreamer, no VMS involved; the other puts the Claude desktop app on physical keys.

How a key becomes an action

Physical keys. Native shortcuts. Nothing in between.

  1. 01

    The client already knows the shortcuts

    Each deck wraps that video client's own documented keyboard shortcuts — playback, PTZ, alarms, bookmarks, view navigation — instead of inventing a private protocol.

  2. 02

    Address any camera or view by number

    Keys can punch a camera or a view by its number or logical ID. A stock install works; you do not have to pre-map every scene on a server.

  3. 03

    No server-side configuration

    Install the plugin, drop actions on keys, press. Mini, MK.2 and XL profiles ship where the client needs them. MIT-licensed, free, open source.
